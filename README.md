# DP Lab — مختبر البرمجة الديناميكية

مشروع تعليمي تفاعلي لمادة Dynamic Programming، بفكرتين مختلفتين عن مشروع مقارنة النصوص والمسارات:

1. **0/1 Knapsack**: تعظيم قيمة العناصر داخل حقيبة بسعة محددة.
2. **Coin Change (Minimum Coins)**: إيجاد أقل عدد من العملات لتكوين مبلغ معين.

## التشغيل
افتح `index.html` مباشرة في أي متصفح حديث. لا يحتاج إلى تثبيت مكتبات أو Backend.

## المميزات
- واجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
- إدخال بيانات مخصصة وأمثلة جاهزة.
- بناء جدول DP وعرض الحالات خطوة بخطوة.
- شرح القرار الذي يحدث في كل خطوة.
- عرض النتيجة النهائية والعناصر/العملات المستخدمة.
- تحليل التعقيد الزمني والمساحي.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع ملف `index.html`.
3. من Settings ثم Pages اختر Deploy from a branch.
4. اختر `main` و`/root` ثم Save.
5. افتح الرابط الذي سيظهر لك بعد النشر.

## الخوارزميات
- Knapsack: `dp[i][w] = max(dp[i-1][w], value[i] + dp[i-1][w-weight[i]])`
- Coin Change: `dp[x] = 1 + min(dp[x-coin])` لكل عملة `coin <= x`.

**التقنيات:** HTML, CSS, Vanilla JavaScript.
